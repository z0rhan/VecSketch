# About
Project work for course Principles of Programming Language. A interpretor for a toy language called VecSketch that can be used to draw shapes.

# Requirements and Installation
On your system,
- python3.14
- tklib

Clone the repo as,
```bash
git clone https://github.com/z0rhan/VecSketch.git
cd VecSketch
```

Make a python virtual environment as,
```bash
python -m venv .venv

```
Activate the venv as,
```bash
source .venv/bin/activate
```

Then install required python packages with,
```bash
pip install -r requirements.txt
```

# Usage
You can run the interpretor as,
```bash
python run.py <path-to-file>
```

There is an example code provided in `examples/`.
